Proposed project

Sona

Sona is a proposed voice assistant. It will help users with physical tasks when they cannot use a screen or keyboard.

Research question

When should the agent speak?

We will examine speech timing, interruption, and error recovery. We will also examine when the agent should give help.

Two proposed interfaces

Sona Mobile

Sona Mobile is the proposed interface for users. Users will speak to the agent during a physical task. Camera input is optional.

Sona Lab

Sona Lab is the proposed interface for researchers. Researchers will set up experiments and examine speech records, events, and response times.

Before development

The team must select the user and task. The team must also define the MVP, test measures, and system design.

Possible measures include response time, interruption success, task completion, user control, and error recovery. The team has no test results yet.
