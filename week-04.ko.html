4회차 정기 모임: 보이스 타로 흐름과 캐릭터

장소
현대차/기아 양재사옥

모바일 보이스 타로 흐름을 구체화하고 Y2K 퀸 캐릭터 방향을 정했습니다. 화면 초안과 탐색적 음성 시험을 바탕으로 다음 개발 작업을 나눴습니다. 전체 서비스의 동작 검증은 아직 완료되지 않았습니다.

이번 모임의 결정

  • 모바일 웹과 리더 한 명으로 시작합니다. 사용자가 요청하면 즉시 음성으로 연결합니다.
  • 소셜 로그인, 수정 가능한 호칭, 리더 프로필과 통화 버튼을 제공합니다. 네이버와 카카오를 기본 로그인 대상으로 검토합니다.
  • 첫 구현에서는 78장 중 카드 번호 세 개를 음성으로 선택합니다. 가능하면 카드 선택 효과를 화면에 함께 보여줍니다.
  • 음소거와 종료 버튼을 제공합니다. 종료 후 선택한 카드와 생성된 대화 요약을 보여줍니다.
  • 밝고 자신감 있는 퀸 캐릭터와 Y2K 시각 방향을 구체화합니다. 백엔드는 Python을 사용합니다.

관찰과 미정 사항

  • 탐색적 음성 시험에서 AI는 무작위 추첨 대신 카드를 골랐다고 답했고, 사용자 정보가 충분하지 않은 상태에서 개인 상황을 추측했습니다.
  • 무작위 추첨 절차, 번호 인식, 끼어들기와 종료 동작을 정의해야 합니다. 한국어 음성 품질과 세션 비용도 시험해야 합니다.
  • 시간 제한이 있는 선불 이용과 10분 이용권을 논의했습니다. 가격, 무료 체험, 연장과 잔여 시간 정책은 미정입니다.
  • 최종 서비스명, 음성 제공자, 저장 정책과 호스팅 구성은 미정입니다. OpenAI 로그인과 사용자 구독을 통한 API 비용 절감은 검증되지 않은 아이디어입니다.

11월 8일까지의 작업

  • 캐릭터 및 기획 담당은 무드보드와 고민 주제별 여러 턴의 대화 예시를 준비합니다.
  • 프론트엔드 담당은 편집 가능한 화면 초안을 공유하고 실제 음성 API에 연결되는 초기 프로토타입을 만듭니다.
  • 백엔드 담당은 기술 스택, 인증, 계정 관리, 데이터, DB와 인프라 구성을 문서화합니다.
  • 무드보드 선정 후 화면의 시각적 일관성을 검토합니다. 작업 담당자와 공통 개발 규칙을 확인합니다.
  • 다음 모임에서 캐릭터 자료, 실제 음성 프로토타입과 백엔드 명세를 함께 확인합니다.
