음성 인터랙션 프로토타입

음성 인터랙션 UI 프로토타입

예정 날짜2026-11-01
예정 시간14:00–17:00 한국 표준시
진행 방식오프라인

활동 기록

2026-11-01 / 14:00–17:00 KST

4회차 정기 모임: 보이스 타로 흐름과 캐릭터

장소
현대차/기아 양재사옥

소셜 로그인부터 리포트 화면까지 모바일 보이스 타로 사용자 흐름을 정의했습니다. 11월 말 최종 발표회 심사 시점에 런칭 가능한 수준의 완성도를 목표로 합니다.

공지 사항

  • 최종 발표회 참석 대상 팀은 11월 말 제출 자료를 기반으로 심사 후 결정됩니다.
  • 자료 제출 이후에도 프로젝트 완성도를 높이는 추가 개발과 구현이 가능합니다.

사용자 화면 흐름

  • 소셜 로그인 가입 화면: 네이버, 카카오, OpenAI.
  • 닉네임 화면: 직접 입력과 랜덤 자동입력을 제공합니다.
  • 메인 화면: 프로필 카드와 전화 걸기 버튼을 제공하며 통화 화면으로 연결합니다.
  • 통화 화면: 하단에는 음소거와 전화 종료 버튼, 상단에는 실시간성을 드러내는 이펙트를 둡니다.
  • 사용자가 사전 정의된 카드 78장 중 세 장의 번호를 음성으로 말하면 화면에 카드 뽑기 이펙트를 보여줍니다.
  • 음성 에이전트가 선택한 카드를 각각 설명한 뒤 사용자와 음성으로 상호작용하며 상담을 이어갑니다.
  • 크레딧을 모두 소진하거나 전화 종료 버튼을 누르면 통화가 끝나고 리포트 화면으로 이동합니다.
  • 리포트 상단에는 선택한 타로 카드, 하단에는 대화 요약을 제공합니다. 요약 생성 중에는 로딩 화면을 표시하며 리딩 종료 후 메인 화면으로 복귀합니다.

캐릭터와 서비스 콘셉트

  • 자신감 있고 직설적인 퀸의 마인드 콘셉트로 타로 리더 한 명을 구현합니다. 추가 여부는 추후 결정합니다.

비용과 결제 방향

  • 10분 단위 이용권을 사용합니다. 7분 상담은 이용권 한 장, 27분 상담은 세 장을 사용하며 남은 3분은 각각 폐기합니다.
  • 비회원 무료 체험 제공 여부는 API 비용을 고려해 추후 결정합니다.

과제와 조정 사항

  • 비회원 무료 체험은 결제를 받지 못하면서 API 비용이 발생합니다. 유료 이용 회원 전환율과 전환 설계가 핵심입니다.
  • 회원가입 유도에 따른 사용자 이탈과 관심 증가 사이의 균형을 고려해야 합니다.

11월 8일까지의 작업

  • 음성 구현 담당: 음성 API를 연결하고 실제 통화 가능한 초기 프로토타입을 제작합니다.
  • 백엔드 담당: 기술 스택, 데이터 구조와 인프라 환경을 명세하고 AWS 계정 세팅을 준비합니다.
  • 디자인 및 기획 담당: Figma 무드보드 제작, 레퍼런스 수집, 타로 리더 예시 대사와 시나리오 작성을 진행합니다.
  • 개발 협업 담당: AGENTS.md를 포함한 팀 Git Flow 가이드라인을 준비합니다.
