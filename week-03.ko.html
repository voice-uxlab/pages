3회차 정기 모임: 보이스 타로와 팀 개발

장소
현대차/기아 양재사옥

MIND DETOXING에서 보이스 타로로 방향을 전환했습니다. 첫 버전은 모바일 웹에서 즉시 연결되는 음성 경험으로 만듭니다. 최종 이름과 음성 제공자는 아직 정하지 않았습니다.

회의에서 결정한 내용

  • 사용자가 고민을 말하고 카드를 고른 뒤 음성 해석을 듣고 후속 질문을 하는 양방향 대화를 만듭니다.
  • 모바일 웹으로 시작합니다. 사용자가 웹 안에서 음성 대화를 시작하며 실제 전화번호는 필요하지 않습니다.
  • 귀엽고 가벼운 시각적 방향을 사용합니다. 구체적인 캐릭터와 디자인은 더 정해야 합니다.
  • 즉시 연결 기능을 먼저 확인한 뒤 예약 통화와 결제를 검토합니다.
  • 분야에 제한 없이 기능 단위로 참여합니다. 기획, 프론트엔드, 백엔드 조율자가 의견 차이를 조정합니다.
  • 목표는 작동하는 제품과 성공적인 12월 16일 데모입니다. Sona는 선택적으로 활용하는 도구입니다.

논의에서 확인한 점

  • 같은 제품 설명에도 서로 다른 사용자 흐름을 떠올렸습니다. 명세에 화면과 대화 순서를 함께 적어야 합니다.
  • AI가 카드 해석도 음성으로 전달해야 합니다. 음성 인사 뒤에 텍스트 결과만 보여주는 방식으로는 의도한 경험을 구현할 수 없습니다.
  • 실제 대화로 한국어 발음, 응답 지연, 끼어들기, 캐릭터 말투를 확인합니다.
  • 음성 제공자를 결정하기 전에 OpenAI와 ElevenLabs를 비교합니다. 두 API의 인터페이스는 서로 다릅니다.

진행 상태와 남은 작업

  • 제품 방향은 정했습니다. 작동하는 제품과 실제 음성 테스트 결과는 아직 없습니다.
  • 다음 검증 기준은 시작, 대화, 카드 선택, 음성 해석, 종료가 이어지는 하나의 완전한 모바일 흐름입니다.
  • 일정안은 11월 30일까지 데모 가능한 제품을 완성한 뒤 발표 연습에 집중하는 것입니다. 제출 일정은 운영진 확인이 필요합니다.
  • 팀장은 명세 초안, API 비교, 공통 개발 환경을 준비합니다. 팀원은 명세를 검토하고 작업을 선택합니다.
  • 대상 사용자, 이름, 캐릭터, 음성 제공자, 비용 한도, 호스팅, 작업 담당자를 확인합니다.

GitHub와 Codex 협업 운영안

  • 아래는 v1.0 이후 개발을 위한 운영 제안입니다. 세부 절차를 회의에서 확정한 것은 아닙니다.
  • 작업 전에 Issue를 만들고 목적, 범위, 완료 조건, 담당자, 검토자를 적습니다.
  • 최신 main에서 작업별 브랜치를 만듭니다. main에 직접 커밋하지 않습니다.
  • Codex에 AGENTS.md와 Issue를 읽게 하고 구현 전에 계획을 확인합니다.
  • 작은 Draft PR을 일찍 엽니다. Issue, 변경 이유, 테스트 결과와 필요한 화면 자료를 첨부합니다.
  • 다른 팀원에게 변경 내용과 사용자 흐름 검토를 요청합니다. Codex 리뷰는 보조 수단으로 활용합니다.
  • 초기에는 팀장이 통합 담당자를 맡습니다. 동료 검토와 CI 결과를 확인한 뒤 Squash merge합니다.
  • 팀장의 변경도 다른 팀원이 검토합니다. 대리 통합 담당자도 정합니다.
  • 충돌은 다른 작업자와 함께 해결합니다. 제품 방향이나 인터페이스 결정은 해당 조율자의 도움을 받습니다.
  • CI로 타입 검사, 린트, 테스트, 빌드를 실행합니다. 운영 비밀키와 유료 API 호출 없이 테스트 어댑터를 사용합니다.
  • 검사를 통과한 main을 테스트 환경에 배포합니다. 데모 환경에 반영하기 전에 핵심 사용자 흐름을 확인합니다.
  • GitHub Projects를 Backlog, Ready, In progress, In review, Done으로 관리합니다. 배포 확인 후 완료 처리합니다.
  • 비밀키, 원본 음성, 개인 대화는 저장소에 올리지 않습니다. 결과물, 검토, 테스트, 문서로 기여를 기록합니다.
  • 팀원에게 원하는 작업, 가능한 시간, 막힌 점, 지원 필요를 확인합니다. 중요한 결정은 저장소에 기록합니다.

기록 근거

  • 팀장이 제공한 전체 회의 녹취를 요약한 기록입니다. 정규 모임 시간은 한국 표준시 14:00–17:00입니다.
  • 정규 모임 이후에도 논의가 이어졌습니다. 이 업데이트에는 활동 사진을 첨부하지 않았습니다.
