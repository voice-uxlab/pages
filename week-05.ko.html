AI 에이전트와 MVP

핵심 기능이 동작하는 MVP

예정 날짜날짜 미정
예정 시간14:00–17:00 한국 표준시
진행 방식오프라인

활동 기록

날짜 미정

5회차 정기 모임: 음성, 디자인과 MVP 구조

장소

음성 후보를 시험하고 디자인 방향을 정했으며 인프라와 서비스 정책을 논의했습니다. 후속 작업과 미정 사항은 회의 당시 기준입니다.

음성 모델

  • 현재 OpenAI 텍스트를 ElevenLabs 음성으로 변환하는 구조의 지연과 제공자 교체 가능성을 논의했습니다. 스트리밍, 웹소켓 지원과 지연 시간은 추가 확인이 필요합니다.
  • Typecast의 미란, 가인 등 목소리를 시험했습니다. 한국어가 더 자연스럽다는 의견이 있었으며, 속도와 감정, 톤을 조절하고 리딩과 질문에 다른 톤을 적용하는 방안을 논의했습니다.

디자인 방향

  • 1108 메탈릭 콘셉트에 Y2K 아날로그 요소를 더하고, 블러 처리된 별 배경과 실버 및 그레이 톤으로 방향을 잡았습니다.
  • 서양 금발 바비 스타일을 마스코트 참고 방향으로 정했습니다. 기존 이미지를 그대로 쓰지 않고 마스코트와 카드 78장에 사용할 독자적 또는 적절한 권리의 이미지를 마련하고 권리를 확인해야 합니다.
  • 디자인 담당자가 각자 폰트 후보 세 개를 준비합니다. 시작 효과음이나 은은한 배경음악은 검토 중입니다.

인프라와 개발

  • MVP 개발 속도를 위해 우선 Vercel을 사용하고 관리 부담을 고려해 AWS는 보류합니다. 비용은 팀 공동 부담을 계획합니다.
  • 웹, 향후 모바일, 백엔드, 명세와 문서를 모노레포에서 관리합니다. 브랜치와 커밋 규칙을 포함한 Git Flow 문서를 작성했습니다.
  • React와 TypeScript 기반 프론트엔드 환경을 설정 중입니다. 유저와 리포트 속성, DB 스키마와 REST API 설계가 필요합니다.

서비스 기획과 미정 사항

  • 10분 단위 충전과 세션 내 미사용분 소멸 방식을 재확인했습니다. 10분, 20분, 30분 표기는 재검토하고 신규 가입자 체험은 API 비용 확인 후 결정합니다.
  • 10대 후반부터 30대 여성을 중심으로 하고 남성은 초기 타겟에서 제외하는 방향을 논의했습니다. 미성년자 관련 법적 사항은 추가 확인합니다.
  • 종료 버튼과 음성 명령 중 방식을 결정해야 하며 음성 인식 실패 가능성을 고려합니다. 연애, 취업과 직장 등 고민 유형을 분류합니다.
  • 친구 궁합 등 소셜 기능은 MVP 이후 아이디어입니다. 선택 동의를 전제로 음성 대화 데이터를 저장해 피드백에 활용하는 가능성을 논의했으며 정책은 미정입니다.

후속 작업과 당시 기한

  • 목소리 후보를 공유하고 ElevenLabs와 OpenAI TTS API의 기능 및 지연 시간을 비교합니다.
  • 디자인 담당자는 각자 폰트 후보 세 개를 준비합니다. 11월 12일 자정까지 UI v1.0을 Figma에 올리고 11월 13일 12:00까지 팀 투표를 진행하기로 했습니다.
  • 11월 15일 전까지 디자인과 음성 연동 구현본을 준비하고 카드 78장의 이미지 레퍼런스를 수집합니다. DB 스키마, 유저와 리포트 속성, REST API 목록을 작성합니다. 위 계획의 완료 여부는 확인되지 않았습니다.
